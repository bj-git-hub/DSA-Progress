# 268. Missing Number
- **Platform:** [LeetCode](https://leetcode.com/problems/missing-number/)
- **Approaches:**
  1. **Brute** — Nested loops, O(n²) time
  2. **Better** — Hashing / frequency array, O(n) time, O(n) space
  3. **Optimal** — XOR of all numbers with indices, O(n) time, O(1) space
- **Status:** ✅ Solved
