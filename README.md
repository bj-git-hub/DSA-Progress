## 🛠 How to Compile & Run

Each `.cpp` file can be compiled and run individually:

```bash
g++ -o output_file program.cpp
./output_file
```

Example:
```bash
g++ -o largest "Striver_DSA/03_Arrays/01_Largest_Element/optimal.cpp"
./largest
```
